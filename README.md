# CRUD Data Mahasiswa

## Deskripsi
Aplikasi ini merupakan sistem CRUD (Create, Read, Update, Delete) sederhana berbasis web menggunakan PHP Native dan MySQL. Aplikasi ini digunakan untuk mengelola data mahasiswa beserta foto profilnya.

## Tema
Data Mahasiswa

## Pengembang
Nama: Reva Dwi Nurrahma

## Fitur
- Menambahkan data mahasiswa
- Menampilkan data dalam bentuk tabel
- Mengedit data mahasiswa
- Menghapus data mahasiswa
- Upload foto profil mahasiswa
- Validasi form menggunakan JavaScript
